# homebrew-neversleeps

Tap do Homebrew para o [neversleeps](https://github.com/philipecomputacao/neversleeps), o app que mantém o MacBook acordado com a tampa fechada.

```bash
brew tap philipecomputacao/neversleeps
brew install --cask neversleeps
```

O app ainda não é notarizado pela Apple: na primeira abertura, botão direito → Abrir (uma vez). O cask é atualizado automaticamente a cada release.
