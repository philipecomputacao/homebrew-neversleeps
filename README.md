# homebrew-neversleeps

Tap do Homebrew para o [neversleeps](https://github.com/philipecomputacao/neversleeps), o app que mantém o MacBook acordado com a tampa fechada. Site: [philipecomputacao.github.io/neversleeps](https://philipecomputacao.github.io/neversleeps/).

```bash
brew trust philipecomputacao/neversleeps
brew tap philipecomputacao/neversleeps
brew install --cask neversleeps
```

O Homebrew atual exige confiar no tap de terceiro antes de tapar. O app ainda não é notarizado pela Apple: na primeira abertura, botão direito → Abrir (uma vez). O cask é atualizado automaticamente a cada release.

Homebrew tap for [neversleeps](https://github.com/philipecomputacao/neversleeps). Third-party taps must be trusted before tapping. Not yet notarized: on first launch, right-click → Open (once).
